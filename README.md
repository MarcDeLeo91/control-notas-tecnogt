# Academia TecnoGT: Control de Notas

Proyecto Maven para validar y registrar las calificaciones de estudiantes.

## Requisitos

- Java 17 o posterior
- Maven

## Pruebas y cobertura

Ejecuta todas las pruebas y genera el informe de cobertura JaCoCo:

```bash
mvn clean test
```

El informe HTML queda en `target/site/jacoco/index.html`.
